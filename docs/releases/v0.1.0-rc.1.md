# v0.1.0-rc.1 release candidate

This is a reviewable release candidate, not a stable release or a
production-sandbox certificate. It creates no rollback guarantee for host
capability effects and does not establish a production approval boundary.

## What remains unqualified

- The fixed ASan corpus exercises native compilation and selected value/
  protocol boundaries, but is deterministic rather than coverage-guided.
- The short coverage-guided targets cover raw framing and request/value
  admission, not the native mruby compiler or C value bridge.
- Sustained native parser/value fuzzing, cross-version ABI compatibility review,
  deployment hardening, and an independent sandbox/security review remain
  release gates for any production use.
